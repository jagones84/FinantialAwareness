# Project Brief: FinancialAwareness

## Mission
Transform the "developer-centric" prototype into a polished, scientific-grade financial simulation app for Android.
The app performs financial optimization (Surplus Optimization) using Genetic Algorithms and Coordinate Search, visualizing results with interactive 3D and 2D charts.

## Core Goals
- **Scientific Rigor**: Accurate optimization logic, correct terminology (Standard Deviation Minimization Weight), and clear visualization of data.
- **User Experience**: Intuitive navigation, professional UI (Material 3), and responsive charts with touch gestures.
- **Accessibility**: Multi-language support (English, Italian, Spanish) and clear guides.
- **Performance**: Efficient simulation and chart rendering.

## Key Features
- **Financial Input**: Detailed profile settings (Age, Savings, Expenses, etc.).
- **Simulation Engine**: Surplus calculation and optimization based on objective function.
- **Visualization**: 3D Surface charts (Utility vs Parameters) and 2D Heatmaps/Lines with contour labels.
- **Multi-language**: EN, IT, ES support.
- **Reporting**: Comprehensive PDF export with units and explanations.
